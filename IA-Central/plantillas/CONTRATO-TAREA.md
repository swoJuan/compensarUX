# Contrato estándar de trabajo entre agentes

- ID de trabajo / fecha de apertura / solicitante:
- Objetivo / plataforma (`ds-figma`, `ds-code`, `drupal`, `zt`, `app`, `qa`, `entrega`):
- Fuente principal (HU y revisión, Figma archivo+nodo, repo y commit):
- Fecha real de verificación de esas fuentes:
- Restricciones DEC y exclusiones:
- Criterios de aceptación y QA:
- Agente responsable / agentes consultados:
- Archivos permitidos (lectura y escritura):
- Componente existente / variante / nuevo / excepción:
- Cambios realizados vs propuestas:
- Evidencia / pruebas ejecutadas / pruebas NO ejecutadas:
- Git status / commit actual / cambios ajenos respetados:
- Aprobaciones recibidas (quién, qué y cuándo):
- Handoff para el siguiente agente:
- Estado documental / pendientes / próximo paso:

**El agente receptor no cambia el alcance ni da por aprobado lo no aprobado.**

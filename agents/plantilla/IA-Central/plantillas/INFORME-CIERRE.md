# Handoff/cierre de tarea

1. **Resultado**: completado, parcial o bloqueado (con evidencia).
2. **Qué se editó**: archivos, commits, tokens, nodos Figma.
3. **Qué se verificó**: comandos, navegador, resoluciones, contraste y resultados reales.
4. **Qué NO se verificó**: límites, herramientas desconectadas y pruebas pendientes.
5. **Decisiones/aprobaciones**: explícitas o pendientes; no dar por aprobadas propuestas.
6. **Cambios documentales**: ID de flujos/componentes/pendientes actualizados en registro.
7. **Estado Git y despliegue**: confirmar si solo local o publicado, con enlace real si existe.
8. **Siguiente acción**: responsable y dependencia.
